How to put the replay on your GitHub profile
  1. Download the GIF and commit it to your profile repository (github.com/<you>/<you>) next to README.md, keeping its file name.
  2. Copy the README markdown and paste it into that README. The image link is relative, so it works as soon as the GIF is committed.
  3. For the MP4: edit your README on github.com and drag the video into the editor. GitHub uploads it and inserts a link that plays inline.
